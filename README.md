# WebOS

A lightweight Windows-inspired desktop simulation for a Fullstack Web Development project.

## Stack

- React + Vite frontend
- Node.js + Express backend
- Local JSON file storage

## Run locally

Requirements: Node.js 20.19+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:5173/.

You can also run `start-app.bat` on Windows. It checks Node/npm, installs dependencies when needed, builds the frontend, starts the local servers, and opens the app.

- Username: `Ishan`

## Project data

Notes are stored in `data/notes.json` and calendar events are stored in `data/events.json`. This is a local educational project, not a production authentication system.
